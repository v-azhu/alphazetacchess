# AlphaZetaChess V0.4.3-beta-2

SearchEngine integration for the already validated Mobility evaluation.

## API

```python
SearchEngine(
    ...,
    use_mobility=False,
    mobility_weight=1,
)
```

Mobility is disabled by default, preserving the V0.4.2 search baseline.

## Apply

From the repository root:

```powershell
python tools/apply_v043_beta2.py
```

The script is deliberately guarded. It expects the V0.4.2 SearchEngine
structure and will abort without writing if the four evaluation call sites
cannot be identified.

Then run:

```powershell
pytest tests/test_search_v043_beta2.py
pytest tests/test_mobility_v043.py tests/test_evaluation_v043.py
```

Do not run the long full suite until these focused tests pass.
