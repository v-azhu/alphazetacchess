# AlphaZetaChess V0.4.3

## Beta-1: Mobility evaluation integration

V0.4.3-beta-1 wires the already-tested Mobility component into the
evaluation function while keeping the feature disabled by default.

### API

`evaluate()` now accepts:

- `use_mobility=False`
- `mobility_weight=1`

The default therefore remains behavior-compatible with V0.4.2.

### A/B model

```text
V0.4.2 baseline
use_mobility=False

V0.4.3 beta
use_mobility=True
```

The weight is deliberately exposed because `1` is only an initial engineering
value. It must be validated with benchmarks and real games before tuning.

### Scope

This checkpoint changes only evaluation. SearchEngine does not yet expose the
mobility switch. That is intentionally deferred to the next checkpoint so
evaluation regressions can be isolated from search integration.

### Acceptance

Run:

```powershell
pytest tests/test_mobility_v043.py tests/test_evaluation_v043.py
```

If green, the next checkpoint is SearchEngine integration followed by a V0.4.2
vs V0.4.3 A/B benchmark.
