# V0.9.16 — TT / PVS A/B Diagnostic

## Goal

V0.9.13–V0.9.15 established that search scores can vary substantially with depth and that Quiescence Search can materially change shallow decisions.

V0.9.16 does not modify the engine. It isolates two interacting search components:

- Transposition Table (TT)
- Principal Variation Search (PVS)

The comparison keeps Quiescence Search enabled and Null Move disabled.

## Variants

For each position and depth:

1. FULL — TT + PVS
2. NO_TT — PVS without TT
3. NO_PVS — TT without PVS
4. NO_TT_NO_PVS — neither TT nor PVS

History Heuristic remains enabled in all variants.

## Positions

The benchmark uses the same six positions as V0.9.15:

- initial
- open_position
- tactical_exchange
- mate_in_one
- free_capture
- exchange_trap

## Results

The user ran both the 2–4 and 3–5 suites.

Across all tested positions and depths, all four configurations returned the same best move and the same score. Every run reported state_ok=True.

At depth 5, removing TT increased search nodes substantially:

- initial: 104,845 -> 204,554
- open_position: 112,066 -> 348,117
- tactical_exchange: 28,605 -> 69,599
- mate_in_one: 1,122 -> 2,211
- free_capture: 5,415 -> 13,147
- exchange_trap: 993 -> 1,780

Removing PVS also increased nodes, but generally less than removing TT. Disabling both produced the largest cost on the larger positions.

### Diagnostic conclusion

Current evidence does not implicate TT or PVS as the source of the previously observed score/depth instability.

The experiment removed TT and PVS independently and together, yet neither best moves nor scores changed on the tested positions.

Therefore, for this suite:

- TT is providing a substantial performance benefit.
- PVS is providing a measurable performance benefit.
- The earlier score instability remains more plausibly associated with search horizon, evaluation, Quiescence Search, or their interaction.

This is a diagnostic conclusion, not proof that TT/PVS contain no bugs. The suite is small.

## Next step

Do not change TT or PVS yet.

The next diagnostic should move deeper into the remaining suspects:

1. isolate evaluation versus search horizon;
2. inspect Quiescence Search and its depth-0 TT interaction;
3. use the curated tactical suite to distinguish evaluation swings from tactical search errors.

A useful next experiment is to compare static evaluation for each root candidate against its fully searched score, then inspect principal variations where the score changes sharply between depths.

No optimization should be added until that diagnostic identifies a concrete cause.
