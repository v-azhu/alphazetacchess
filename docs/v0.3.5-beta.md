# V0.3.5-beta — Tactical Regression Fix

The first tactical regression exposed a **test-position defect**, not yet an
engine defect.

The original free-rook position placed both generals on the same file with no
intervening piece. Under Xiangqi's flying-general rule that position is
illegal. The search therefore correctly rejected moves that did not resolve
the resulting check, including the apparent free-rook capture.

The position now includes a red pawn between the generals, making the test
position legal while preserving the intended tactical motif.

## Rule

Regression positions must themselves satisfy the engine's legality rules
before their search result is asserted.

## Next step

Run the complete test suite. If the corrected position passes, continue
validating the remaining tactical tests before changing core search code.
