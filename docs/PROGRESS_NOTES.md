# AlphaZetaChess Progress Snapshot — 3,957 real external games imported

Snapshot date: 2026-09-06

## What happened this checkpoint

User pointed out that self-play data collection is bottlenecked by the
same weak hardware constraint that limited MCTS/self-play work
earlier, and that `trainingdata/` already contains ~140k real human/
engine Xiangqi games sitting unused (WXF world-federation games +
dpxq database games, sourced from
https://github.com/CGLemon/chinese-chess-PGN). Real tournament games
are far more diverse than a self-play corpus generated by this
project's own comparatively weak engine, at zero additional self-play
compute cost.

**Built `tools/import_external_games.py`** to convert these
ICCS-notation `.pgns` files into this project's own V0.5.1 record
format, so the existing `tools/label_positions_with_pikafish.py` works
on them unchanged.

**The coordinate-mapping question needed real verification.** First
attempt (replay every move under both possible file-letter
orientations, check legality) was a dead end: Xiangqi's rules are
left-right symmetric, so BOTH orientations produced 100% legal moves
across 100 test games — legality alone can never distinguish an
orientation from its mirror image for a symmetric-rule game. Resolved
via two independent, converging external sources instead: the
rec.games.chinese-chess FAQ's authoritative ICCS spec, and the fact
that these exact `.pgns` files' own embedded starting-position FEN is
byte-for-byte identical to `core/fen.py`'s own output.

**Every decoded game is still re-validated against the Rule engine**
as a real quality gate (not just a formality): discarded whole on the
first illegal move during replay. Result: **0 out of 3,957 processed
games failed validation** — strong practical confirmation the mapping
is correct, not just correct on paper.

**Imported 3,957 real games** (2,651 WXF + 1,306 dpxq) into
`data/external_games.jsonl` — ~40x more games than the 99-game
self-play corpus, averaging 84.7 moves/game. Result distribution
(1519 Red / 1164 Black / 1274 draws) matches real Xiangqi theory's
expected small first-move advantage for Red — another sanity check
the pipeline behaves sensibly.
