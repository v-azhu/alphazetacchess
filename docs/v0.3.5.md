# AlphaZetaChess V0.3.5 — Search Stability & Tactical Regression

## Goal

V0.3.5 establishes regression gates for the search stack before further
evaluation and performance work.

The focus is on invariants rather than forcing one exact best move when
multiple moves can have the same minimax value.

## Scope

- Legal best-move guarantee.
- Determinism for fresh identical searches.
- PVS must preserve the minimax score.
- Transposition-table use must preserve the minimax score.
- Quiescence-enabled search must still return a legal move.

## Important principle

A different best move between Quiescence OFF and ON is not, by itself, a
correctness failure. Quiescence deliberately changes the horizon and may
discover tactical consequences that a nominal-depth search misses.

Likewise, tests should avoid asserting one exact move when several moves have
equal value.

## Acceptance gate

Run:

```powershell
pytest
```

V0.3.5-alpha passes when the complete existing suite and the new
`tests/test_search_v035.py` tests are green.

## Next checkpoint

After this framework is validated, add a small set of explicit tactical
positions for forced captures, recaptures, checks, and horizon-effect cases.
Only after those tests are stable should search-performance optimization begin.
