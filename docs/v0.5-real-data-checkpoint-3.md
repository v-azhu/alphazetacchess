# V0.5 — Third Real Data Checkpoint (2026-09-05): three open questions answered

## What this is

The user ran the three exact comparisons `docs/roadmap.md`'s hand-off
suggested, then interrupted the run early because depth=3 games are
slow. The interrupted run still appended 36 complete, valid records
(no partial/corrupt lines — `append_record` only ever writes after a
game finishes) before stopping, bringing `data/selfplay.jsonl` to
**99 real games**. All three questions this checkpoint's data was
aimed at now have real, if still moderate-sample, answers.

## 1. Does the opening book help?

```
20 games (--a-use-opening-book --random-opening-prob 0):
  Book ON: 10 wins, Book OFF: 10 wins, 0 draws
  Score rate: 50.0%, Elo diff: +0
```
**No measurable difference**, at least not yet. One notable side
observation: **zero draws across all 20 games** — every single game
was decisive. That's a real contrast with this corpus's overall ~60%
draw rate, and worth a tentative explanation: with
`--random-opening-prob 0`, both sides play fully deterministically
except for whatever the book supplies, so each game likely followed
one of a small number of *fixed* early lines (book moves are
themselves drawn from `self.opening_book`'s recorded stats, not
random) rather than the wide, noisy variety `RandomizedOpeningEngine`
normally injects — a narrower, more decisive opening repertoire could
plausibly produce sharper, less drawish middlegames. This is a
hypothesis, not a finding; distinguishing "the book makes games sharper"
from "20 games is just a small, noisy sample" needs more data.

## 2. Does depth=3 beat depth=2?

```
12 games (--a-depth 3 --b-depth 2):
  Depth3: 4 wins, Depth2: 1 win, 7 draws
  Score rate: 62.5%, Elo diff: +88.7
```
**Yes — the first checkpoint in this project's self-play history to
show a real, meaningfully-sized effect.** +88.7 Elo for one extra ply
of search is very much in line with general chess-engine intuition
(deeper search reliably beats shallower search, all else equal) and
is the most confidently interpretable result of the three — not
because the sample is huge (12 games is still modest), but because
the direction matches strong prior expectation and the magnitude
isn't a borderline 50-52% coin-flip. Still worth more games before
citing a precise Elo number, but "depth=3 is stronger than depth=2"
is about as safe a conclusion as anything in this project's data so
far.

## 3. Does `use_endgame_heuristics` show a different result at depth=3?

```
4 games (--a-depth 3 --a-use-endgame-heuristics --b-depth 3):
  ON: 2 wins, OFF: 2 wins? (raw: 5 wins/4 wins/20 draws when combined
  with the existing 25 depth=2 comparison games)

Combined (all 29 use_endgame_heuristics on-vs-off games, depth=2 and
depth=3 together):
  ON wins: 5, OFF wins: 4, draws: 20
  Score rate: 51.7%, Elo diff: +12.0
```
Only 4 new depth=3 games were completed before the run was
interrupted — nowhere near enough on their own to say anything about
depth=3 specifically. Combined with the existing depth=2 data, the
overall picture across 29 games (+12 Elo, well within noise) is
consistent with the second checkpoint's depth=2-only null result:
still no clear evidence `use_endgame_heuristics` helps. **Both the
opening book and `use_endgame_heuristics` remain off by default** —
nothing here changes that.

## Endgame-phase analysis on the full 99-game corpus

```
python tools/analyze_endgame.py --input data/selfplay.jsonl
  Reached endgame phase: 37/99 games
  Average endgame onset ply: 68.0
  Positions with a Rook/Cannon edge at onset: 20 (tied: 17)
    Favored side won 10/20 (50%), lost 1, drew 9
```
This is the **first run where the "sample too small" note doesn't
print** — 20 decided positions is exactly the tool's own threshold for
a number worth looking at. And the number is a flat, unambiguous 50%.
Combined with finding (3) above, the endgame-heuristic hypothesis
(Rook/Cannon value shift in the endgame) has now had a real, if not
huge, chance to show itself and hasn't — consistent across two
different measurement approaches (direct A/B comparison, and the
independent onset-material-edge analysis).

## Opening book rebuilt again

`data/opening_book.json` rebuilt fresh from all 99 games: **1330

63 games).

## What this checkpoint does and doesn't establish

**Reasonably confident**: depth=3 beats depth=2 by a real, meaningful
margin (+88.7 Elo on 12 games, direction matches strong prior).

**Still genuinely unclear, not just "small sample"**: whether the
opening book or `use_endgame_heuristics` help at all — both have now
been tested at moderate sample sizes (20 and 29 games respectively)
and both show scores indistinguishable from 50%. This is meaningfully
different from the earlier checkpoints' "too small to tell" — these
are closer to actual (if still not definitive) null results.

**Not tested**: `use_endgame_heuristics` specifically *at* depth=3
with an adequate sample (only 4 games) — the combined-depth number
above is a reasonable interim summary but doesn't isolate whether
depth interacts with the heuristic's effectiveness.

## Next step

If continuing the V0.5 data-collection line at all, the depth=3
`use_endgame_heuristics` comparison is the one open thread — but
depth=3 games are slow enough that the user has already hit that
limit once. Given depth=3 vs depth=2 is now a fairly confident real
result and the other two comparisons both cleared the "not just too
small" bar and came back null, **this project is turning to V0.6
(neural evaluation / MCTS) next** rather than continuing to grind out
more depth=3 games for diminishing certainty on two already-answered
(negative) questions. See `docs/roadmap.md`'s V0.6 section going
forward.
