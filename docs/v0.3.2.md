# V0.3.2 — Transposition Table

## Goal

Reduce repeated search of identical Xiangqi positions while preserving
the exact V0.3.1 search result.

## Design

### Zobrist Hash

`Board.zobrist_hash` is maintained incrementally during `move()` and
`undo()`. The hash contains:

- piece type
- piece color
- square
- side to move

The random keys are deterministic so benchmark runs are reproducible.

### Transposition Entry

Each entry stores:

- searched depth
- score
- bound type: EXACT / LOWER / UPPER
- best move coordinates

The root color is included in the TT key because scores are currently
evaluated from the root player's perspective.

### Bound Semantics

- EXACT: the stored score is the exact minimax value.
- LOWER: the node failed high; the score is a lower bound.
- UPPER: the node failed low; the score is an upper bound.

A stored entry is usable for cutoff only when its stored depth is at
least the requested search depth.

### Move Ordering

A TT best move is tried first at the corresponding node. This makes the
TT useful not only as a cache but also as an additional source of Alpha-
Beta move ordering.

## Scope

V0.3.2 deliberately does NOT introduce:

- PVS
- Quiescence search
- null-move pruning
- history heuristic
- killer moves
- advanced replacement policies

Those belong to later experiments so that each optimization remains
measurable.

## Acceptance Criteria

1. Existing tests remain green.
2. Zobrist hash survives arbitrary move/undo round trips.
3. Search with TT returns the same score and best move as search without TT.
4. TT reduces or does not increase node count on reference positions.
5. TT statistics expose probes, hits and cutoffs.
6. The benchmark records TT performance against the V0.3.1 baseline.
7. No change to Xiangqi rules or evaluation semantics is introduced.

## Known Limitation

The first implementation uses a simple dictionary with deterministic
single-entry eviction when full. This is intentionally conservative.
A stronger replacement scheme can be benchmarked separately later.
