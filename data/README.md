# Self-Play Data

This directory holds JSON-lines game records produced by
`tools/self_play.py` (see `docs/v0.5.1.md`). Each line is one complete
game record: full move sequence, result, and the engine configuration
used for both sides.

Not committed to git by default (see `.gitignore`) since this is
generated data that grows over time and can always be regenerated by
re-running `tools/self_play.py` with the same configuration -- though
if you want to preserve a specific corpus (e.g. before changing an
evaluation term's default), it's plain JSON-lines text and safe to
commit deliberately whenever that's useful.
